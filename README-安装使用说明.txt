福彩3D 七码胆组预测工具（PWA 版）使用说明
=============================================

这是一个可安装的网页应用（PWA），手机和电脑都能用，安装后像普通 App 一样打开。

【电脑上使用】
1. 双击“启动服务-电脑用.bat”，会自动启动本地服务并打开浏览器。
   （如浏览器没自动打开，就手动访问 http://localhost:8000/index.html）
2. 浏览器地址栏右侧会出现“安装”图标（Chrome/Edge），点它即可把工具装到桌面/开始菜单。

【手机上使用（同一 WiFi）】
1. 先在电脑上运行“启动服务-电脑用.bat”。
2. 查电脑局域网 IP：Win 键输入 cmd，执行 ipconfig，找 IPv4 地址（如 192.168.1.10）。
3. 手机浏览器访问 http://电脑IP:8000/index.html
4. 用浏览器菜单“添加到主屏幕/安装应用”，即可像 App 一样使用。

【长期使用（可外网访问，可选）】
把整个“福彩3D七码工具-PWA”文件夹上传到任意静态空间（GitHub Pages、Netlify、Vercel 等），
用手机/电脑浏览器打开对应网址，即可安装到主屏幕，离线也能用。

注意：本工具仅供娱乐参考，不构成投注建议。
